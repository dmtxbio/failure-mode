# Changelog

## v0.1.0 — 2026-09-28

Initial public release by [@dmtxbio](https://github.com/dmtxbio).

- API ingestion and reproducible snapshot of 458 openFDA CRL records, with source text for 457.
- SQLite full-text search, shared filters, charts, source-letter details, and CSV/JSONL exports.
- 18 candidate review areas with exact evidence spans and versioned rules.
- Private development planning workspaces with notes, review statuses, owners, and portable exports.
- Read-only REST API and official-SDK MCP adapter with four tools.
- Detached local launcher, Docker recipe, automated checks, and source methodology.

Topic labels are automated discovery aids awaiting expert validation. The disclosure corpus is selective and cannot establish approval probabilities. One source record awaits release. Browser automation could not complete the workspace file-picker restore test; restore validation tests pass. The Docker recipe has not been verified by a container build.
